Vibe Engineering with AI Coding Agents

Aik practical hands-on course jo aapko “vibe coding asal mein kya hai?” se le kar AI agent ke sath real apps ship karne tak le jata hai — aur sath hi yeh samajhata hai ke background mein asal mein kya ho raha hai. SMIT mein Muhammad Uzair Khan ka sikhaya gaya course.

🎮 Aik prompt se game banayein 🧠 LLMs asal mein kaise kaam karte hain 📄 agents.md mein master banein ⚡ YOLO mode mein Kanban app ship karein 🤖 AI digital twin banayein ⌨️ Claude Code CLI par command hasil karein 🔁 Ralph loops aur autonomy 🔌 MCP, Skills aur Plugins 🧭 Revision aur recap 🤖 Sub-agents, hooks aur plugins

Shuru se aakhir tak padhein, ya kisi bhi topic par jump karein. Har page mukammal hai aur agle page se juda hua hai.

Hands-on labs

Aasteenein charha lein

Do guided, self-paced labs. Koi grading nahi, koi pressure nahi — sirf practice. Dono free tiers par kaam karti hain.

Lab 1 · ~35 min

Aik prompt, aik app →

Aik sentence se working app generate karein, follow-ups se behtar banayein, phir wohi prompt dobara chala kar divergence dekhein. Non-determinism ka pehla tajruba.
Lab 2 · ~50 min

agents.md likhein, YOLO mein build karein →

Real agents.md likhein, starter clone karein, aur Cursor ko plan → build → test → feedback ke zariye drag-and-drop Kanban board banane ke liye chalayein.

✓ In classes ke ikhtitam par aap…

  • Aik single prompt se working app generate kar sakte hain aur conversation ke zariye usay behtar bana sakte hain.
  • Wazeh kar sakte hain ke LLM kya kar raha hai — tokens, memory, reasoning, tools, loops — aur "agent" ki precise tareef bayan kar sakte hain.
  • Aik tight aur mo-assar agents.md likh sakte hain aur samajh sakte hain ke context window results ko kaise shape karta hai.
  • Tools aur models ke darmiyan soch samajh kar chunao kar sakte hain, aur jaan sakte hain ke YOLO kab safe hai.
  • Real applications ko build, review aur debug karne ke liye AI-native IDE (Cursor) ko plan aur YOLO modes mein drive kar sakte hain.
  • OpenRouter ke zariye AI digital twin ke sath portfolio site ship kar sakte hain — aur uski har line ko own kar sakte hain.
  • Terminal se Claude Code install aur drive kar sakte hain — aur OpenCode, AMP, OpenRouter aur Ollama ke zariye free ya cheap models chala sakte hain.
  • Rozmarrah ki commands, shortcut keys aur **sessions, checkpoints aur Git** ke safety net par command hasil kar sakte hain — aur YOLO aur Ralph loops ko zimmedari se chala sakte hain.
  • Claude Code ko MCP servers, skills aur plugins ke sath supercharge kar sakte hain — aur wazeh taur par jaan sakte hain ke kab kis cheez ki zaroorat hai.
  • Poore course ko aik mental model mein consolidate kar sakte hain — eight stages aur control↔autonomy dial.
  • Claude Code ke sath multi-agent setup chala sakte hain: custom commands, sub-agents, hooks, aur aapka apna plugin + marketplace.
