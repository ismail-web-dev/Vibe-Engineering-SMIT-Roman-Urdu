FeatureDev plugin & iska disciplined process

FeatureDev se miliye — Anthropic ka apna plugin jo Claude Code ko aik disciplined, staged feature-build process ke zariye le jata hai. Ralph loops ka bilkul ulat: rails, reviews, aur repeatable discipline.

🎯 Goal: discipline install karna⏱️ Read: 14 min🧪 Type: concept + setup

Hum tickets read kar sakte hain aur GitHub drive kar sakte hain. Ab woh hissa jo is poori cheez ko disciplined banata hai: aik plugin jo feature build karne ke liye Claude Code ko aik structured, repeatable process ke zariye chalata hai. Isay FeatureDev kehte hain, yeh Anthropic ka official plugin hai, aur yeh pichle hafte ke wild Ralph loops ka bilkul ulat hai.

01Sahi tareeqe se plugin install karein

Claude Code mein wapis aakar, marketplace browse karne ke liye /plugin chalayein. Aapko bohot se options nazar aayenge — bashamool aik official GitHub plugin (thori mukhtalif environment-variable auth ke sath, lekin yeh hamare MCP setup ki tarah hi kaam karega). Yeh woh nahi hai jo humein aaj chahiye. Humein FeatureDev chahiye.

claude
/plugin            # browse the marketplace, arrow to FeatureDev, Enter

02FeatureDev asal mein kya hai

FeatureDev naya feature build karne ke liye Claude Code ko aik disciplined, multi-stage process ke zariye guide karta hai — codebase explore karne, architecture design karne, aur quality review karne ke liye specialised agents ke sath. Yeh model ko rails par rakhta hai.

Ralph loops

🌀 Chaos & autonomy

Mukammal azadi: “10 dafa try karo, dekhte hain kya hota hai.” Tez, exploratory, aur unpredictable.

FeatureDev

🛡️ Rigour & rails

Wazeh stages aur reviews ke sath aik structured, keep-you-honest process. Predictable aur thorough.

Agar Anthropic isay use karta hai, to yeh aik mazboot signal hai

FeatureDev aisi cheez hai jise Anthropic apne software development ke liye internally use karta hai. Kisi workflow ke liye is se behtar recommendation nahi ho sakti.

03Project scope par install karein

Jab aap install karte hain, to Claude Code scope ke bare mein poochta hai:

User scope

Sirf aapke liye

Yeh plugin aapke tamam projects mein dastyab hota hai, lekin sirf aapki machine par.

Project scope ✓

Repo ke har shaks ke liye

Project ke andar .claude folder mein likhta hai — isay commit karein aur har teammate ko wohi plugin mil jayega. Yeh wohi hai jo hum chahte hain.

Project scope chunein. Claude Code aik .claude folder banata hai — aik real file jise hum commit kar sakte hain, taake poori team is disciplined setup ko share kare.

04Disciplined process, stage by stage

Seedha code par chhalang lagane ke bajaye, FeatureDev aik sequence follow karta hai. Is shape ko samajhna aapko boss rehne mein madad deta hai aur yeh pehchanne mein ke kab koi stage skip ho jati hai (aisa hota hai — is par mazeed baat jald hogi).

On-rails flow ka aik numaindah view: explore → clarify → architect → plan → implement → review → finalize.
Stages skip ho sakti hain — hoshiyar rahein

Aik disciplined plugin bhi mukammal tor par reliable nahi hota. Aaj baad mein Claude khamoshi se quality-review stage ko skip kar deta hai aur tabhi manta hai jab hum us se seedha poochte hain. Sabaq: stages ko janein, aur check karein ke har stage waqai hui ya nahi. Boss ab bhi aap hi hain.

05Housekeeping: .gitignore aur setup commit karna

Do aasan aur qeemti kaam — aur hum yeh Claude se karwate hain. Pehle, aik achhi .gitignore taake hum kabhi secrets ya fazool files commit na karein. Aik single prompt sab handle kar leta hai:

“Please create a boilerplate .gitignore for this new project for a typical Python FastAPI / Next.js web app, then commit and push to GitHub.”

Claude aik samajhdar .gitignore likhta hai (khas tor par .env shamil karta hai taake API keys kabhi leak na hon), phir commit karta hai, push karta hai, aur pichle merge ko sync karne ke liye pull bhi karta hai. GitHub check karein — nayi .gitignore wahan mojood hai. Doosra, FeatureDev ko project scope par install karte waqt banne wale .claude folder ko yaad rakhein: usay bhi commit karein, taake har teammate ko wohi plugin virsay mein mile.

.claude ko commit karna kyun zaroori hai

Yeh project scope ki aik khamosh taqat hai: aapke plugins, aur baad mein aapki skills aur project CLAUDE.md, sab repo mein rehte hain. Repo clone karein aur aap poora working setup clone kar lete hain — har koi inhi rails ke sath code karta hai.

✓ Aham baatein

  • /plugin ke sath plugins browse aur install karein; hum FeatureDev install karte hain, jo Anthropic ka official feature-building plugin hai.
  • FeatureDev Ralph loops ka ulat hai — specialised agents ke sath aik disciplined, on-rails, multi-stage process.
  • Project scope par install karein taake .claude folder ko commit karke team ke sath share kiya ja sake.
  • Stages aam tor par yoon chalti hain: explore → clarify → architect → plan → implement → review → finalize — aur koi stage skip bhi ho sakti hai, is liye verify karein.
  • Claude se .gitignore banwayein (.env lazmi shamil karein!) aur .claude commit karein taake setup repo ke sath move kare.
