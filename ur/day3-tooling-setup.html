Class 4 · 4.1

Tools, setup & real agents.md ko samajhna

Baatein kam, kaam zyada. Chaar IDE agents se miliye, apna environment tayyar karein, starter clone karein, aur aik mukammal agents.md file ko line by line samjhein — wohi file jo kal ke build ko chalayegi.

🧰 Goal: apne project ko set up aur understand karna⏱ Read: 10 min🟡 Pehla “yellow” (hands-on) din

01Aaj ke liye teen bunyadi usool

Usool 1

Sab kuch optional hai

Maqsad mukhtalif agentic platforms ka tajruba hasil karna hai. Chahein to sab try karein, ya sirf dekhein aur apna pasandeeda tool chunein — Cursor, Copilot, ya agle hafte Claude Code. Sab karna zaroori nahi.

Usool 2

Aapke results mukhtalif honge

Mukhtalif models, mukhtalif plans, free tiers — aapka output demo se thora mukhtalif hoga. Yeh is tajrubay ka hissa hai. Jo aapke paas hai usi se kaam karein.

Usool 3

Pareshaan mat hon

Agar agent ulta seedha code likhne lage (downgraded models par aam hai): sabr rakhein, feedback dein, aur sab se barh kar simplify, simplify, simplify. Scope ko chhota karein, pehle kuch basic chalayein, phir aage barhein.

Jab phans jayein to raste mojood hain

Sab delete karein aur dobara shuru karein. Model switch karein. Ya us product ko chhor kar aglay par chale jayein — aaj bohat se options hain. Sab se ahem baat: is process ko enjoy karein.

02Chaar IDE agents jinhein aap dekhenge

ToolMakerNotes
CursorAnysphereVS Code par mabni, bohat popular, free trial. Aaj ka main driver.

03Setup karein: Node & terminal

Cursor ko dobara kholein (agar zaroorat ho to File → New Window) aur Class 2 ke Instant project par jayein. Phir agar aapke paas nahi hai to Node.js install karein — kal ki app ke liye yeh runtime zaroori hai.

Built-in terminal kholein

Cursor mein, View → Terminal se terminal pane khulta hai. Is se ghabraiye mat — yeh 1980s jaisa dikhta hai, magar yahan sirf commands type karni hoti hain. + button se mazeed terminals add karein.

nodejs.org se Node install karein

Apne platform (macOS/Windows/Linux) ke mutabiq installer download karein, ya package manager use karein. Course resources follow karein agar koi cheez mukhtalif lage.

Tassali karein ke kaam kar raha hai

Version check run karein. v22 ke baad ka koi bhi version behtareen hai.

Cursor terminal
$ node --version
v22.14.0            # 22 ke baad ka koi bhi version sahi hai

Navigate karein & starter clone karein

Terminal ke kuch bunyadi basics, phir hum starter repo pull karte hain:

bash / powershell
$ pwd                 # print working directory — main kahan hoon?
/Users/ed/projects/instant

$ cd ..               # aik level oopar jayein, projects folder mein

$ git clone https://github.com/MuhammadUzair1/Vibe-Engineering-SMIT.git
Cloning into 'kanban'...   # starter ab aapke computer par hai

$ cd kanban
PC vs. Mac

Windows par aapko forward slashes ke bajaye backslashes dikhenge — concept aik hi hai. Phir Cursor mein project switch karein: File → New Window → Open Project aur kanban folder kholein. Jab top-left par block capitals mein KANBAN nazar aaye to samjhein kaam ho gaya.

Mufeed shortcuts: file sidebar ko ⌘/Ctrl B se toggle karein, aur agent chat panel ko ⌘/Ctrl ⌥ B se.

04Real agents.md ko parhna

Poori repo aik single file par mushtamil hai: aik hand-written agents.md. (Aik file ke liye cloning ka lamba process — magar clone karna achi practice hai.) Jab hum agent chalate hain to yeh file default taur par uski memory mein load ho jati hai. Right-click → Open Preview karein taake dekhein agent isay kaise parhta hai. Yeh hai iska structure, section by section:

kanban / agents.md
# Kanban project

## Business requirements
- An MVP of a Kanban-style project-management web app.
- One board only. Five fixed columns that can be renamed.
- Each card has a title and details only.
- Drag-and-drop to move cards between columns.
- Add a card; delete a card. Nothing more — no archive, no search.
- Priority: a slick, professional, gorgeous UI. Open with dummy data.

## Technical details
- A Next.js app, in a subdirectory called `frontend`.
- No persistence. No user login.
- Use popular libraries, as simple as possible, elegant UI.

## Color scheme
- (my usual deck colors — change or delete freely)

## Strategy
- Write a plan with success criteria for each phase, to be checked off.
- Scaffold, then rigorous unit testing, then execute the plan.
- Extensive integration testing with Playwright; fix defects.
- Only complete when the MVP is finished and tested, server running.

## Coding standards
- Latest, idiomatic library versions as of today.
- Keep it simple; never over-engineer; always simplify.
- No unnecessary defensive programming. No extra features.
- Be concise. Short READMEs. IMPORTANT: no emojis, ever.
Isay is tarah kyun likha gaya

Wazeh, precise, aur zyada tar positive

Requirements ko saaf suthra bayan karein taake wazeh ho ke kya banana hai. Simple shuru karein (“one board”) — 3 hafton mein complex cheezein banane ka waqt milega. Ahem baaton par thori repetition theek hai.

Exact copy karna zaroori nahi

Aik living document

Aap minimal file likh sakte hain, run karein, result delete karein, aur ghaltion ko theek karne ke liye dobara likhein — yeh aik intehai kamyab iterative technique hai. Technical details, colors aur strategy sab optional hain; model khud bohat kuch infer kar leta hai.

“No emojis, ever” kyun likha gaya

LLMs ko har jagah emojis daalna pasand hota hai. Ajeeb lagne ke ilawa, yeh kuch Windows PCs par builds ko break kar sakte hain. Agar aapko emojis pasand hain to yeh line hata dein aur khul kar use karein.

05Cursor settings — apna risk level chunein

Settings kholein (⌘/Ctrl ⇧ J) → Agents → Auto-run. Yeh aapka apna faisla hai:

SettingKya hota haiKab use karein…
Ask every timeHar action ko approve karein; aap har file dekhte hain jo yeh banata hai.Aap naye hain aur har step ko dekhna chahte hain.
Auto-run (sandboxed)Automatically chalta hai magar mehdood/contained rehta hai.Aap safety net ke sath speed chahte hain.
Run everything, unsandboxed (YOLO)Koi approval nahi; seedha execute hota hai.Aap risks samajhte hain aur project low-risk hai — jaise yeh wala.
Kanban build ke liye mashwara

Yeh project low-risk hai, is liye YOLO befikr hokar use kiya ja sakta hai. Agar aap sure nahi hain to ask every time ya sandboxed se shuru karein, uske actions dekhein, aur jab tayyar hon to YOLO par switch kar lein.

Build ke liye tayyar →

Aapke paas tools hain, aik saaf project, real agents.md, aur risk level set ho chuka hai. Agla qadam: Cursor ko YOLO mode mein chalayein Kanban app banane ke liye — ya seedha Lab 2 par jayein aur khud build karein.

✓ Ahem takeaways

  • Aaj ke tools optional hain aur results mukhtalif ho sakte hain — sabr rakhein aur phansne par simplify karein.
  • Chaar ahem IDE agents: Cursor, Copilot, Codex, Antigravity.
  • Terminal ki bunyadi commands — pwd, cd, git clone — aur Node v22+ se setup mukammal ho jata hai.
  • Aik achi agents.md precise, simple, mostly positive, aur living document hoti hai.
  • Cursor auto-run level risk ke mutabiq chunein; YOLO low-risk builds ke liye munasib hai.
