Class 11 · 11.3

The pro toolkit: Claude Code, MCP, skills & plugins

Week 2 ne aapko aik aam AI IDE use karne wale se badal kar aik professional coding agent ko command karne wala engineer bana diya. Aao is pure toolkit ko dobara jor kar dekhein taake samajh aaye ke tamam hissay aapas mein kaise fit hotay hain — aur un extensions ki bunyaad rakhein jin par week 3 tameer hoga.

🎯 Goal: tools ko dobara organize karna⏱ Parhein: 15 min🧠 Type: revision

Yahan mojood har cheez aap pehle hi kam az kam aik baar practical kar chuke hain. Asal maqsad ab fluency hasil karna hai — kisi tool ko bina documentation dekhay pehchanna, aur yeh janna ke har tool kis maqsad ke liye wajood mein aya.

01Claude Code CLI

Claude Code aapke terminal mein rehta hai aur poore project ko apna workspace samajhta hai. Woh commands jo aap rozana use karte hain:

CommandKya karta hai
/loginAapka Anthropic account authenticate karta hai.
/initProject ko scan karta hai aur shuruaati CLAUDE.md draft karta hai.
/contextCheck karta hai ke context window kitni bhar chuki hai.
/compact · /clearContext bachata hai, ya naye task ke liye use bilkul saaf kar deta hai.
/agents · /hooks · /pluginWoh pro menus hain jinhein hum finale week mein khol kar customize karein ge.
.claude folder ki ahmiyat

Taqreeban har pro feature wapas isi aik folder par aati hai: aapke project ka .claude/ directory. Custom commands, skills, sub-agents, hooks aur project settings sab yahan rehti hain — aur kyunke is folder ko Git mein commit kiya ja sakta hai, aapki poori team inhein inherit kar leti hai. Ise hamesha yaad rakhein; yeh Class 12 ki reedh ki haddi hai.

02Models & providers

Do alag alag faislay hain jinhein aapas mein mix nahi karna chahiye: kaun sa tool (Claude Code, Cursor, OpenCode...) aur kaun sa model use chala raha hai. Aur aap kisi aik par paband nahi hain — sirf aik provider API key ke zariye aap usi tool ko saste ya muft models ki taraf mor sakte hain.

Frontier

Top quality

Opus-class models mushkil reasoning aur baray architectural refactors ke liye. Thora slow aur mehanga, lekin jahan quality zaroori ho wahan qeemat wasool hoti hai.

Fast frontier

Speed + smarts

Cerebras / fast providers ke sath bijli ki tezi se jawabat — tight iteration loops ke liye behtareen.

Free / local

Saste experiments

OpenRouter, free tiers, ya apni machine par chalne wala local Ollama — practice aur experimentation ke liye perfect.

Leaderboard par nazar rakhein

Model rankings har maheene badalti rehti hain — pichlay maheene ke favourite model par andha bharosa karne ke bajaye artificialanalysis.ai jaisi sites check karein. Asal hunar kisi aik winner ka naam ratna nahi, balkay har kaam ke liye soch samajh kar model pick karna hai.

03Sessions, Git & Ralph loops

Safety net ke bina autonomy sirf be-waqoofi aur nuqsan ka risk hai. Week 2 ne aapko yeh safety net faraham kiya:

Sessions & checkpointsrewind

Project ki history mein aagay aur peeche jayein; kisi kharab step ko undo karein bina apna baqi kaam zaya kiye.

Git: Asal safety netcommit often

Har risky move se pehle clean commit karein. Har commit aik safe save point hai jis par aap hamesha wapas laut sakte hain.

YOLO mode--dangerously-skip-permissions

Agent ko bina har step par ijazat maangey tezi se kaam karne dein — super fast, lekin sirf tab jab Git ka safety net mojood ho!

Ralph loopsautonomy

Agent ke gird loop chalayein taake woh ghanton autonomous build karta rahe. Yeh hands-off autonomy ka pehla maza tha — aur week 3 ke hooks aur swarms ki bunyaad.

04The Big Three: MCP, skills & plugins

Class 8 ka ahem mod (inflection point). Yeh teeno agent ki salahiyat ko barhatay hain, aur teeno aik hi bunyadi concept par kharay hain: tools.

Aik plugin skills, commands, sub-agents aur hooks sab ko aik sath package kar sakta hai — jaisa hum Class 12.6 mein apne haathon se banayein ge.

05Kaun sa kab istemal karein?

Aasaan usool (Rule of Thumb)

MCP tab use karein jab aapko kisi external system ko connect karna ho (Jira board, GitHub repo, live database). Skill tab use karein jab aap agent ko koi specific tariqa sikhana chahein (Cerebras API call karna, project ka coding style follow karna). Plugin tab use karein jab aap apne pure setup ko bundle kar ke team ke sath share karna chahein. Hamesha sab se light aur simple option chunein — jo aam taur par aik skill hoti hai.

✓ Aham Nakaat (Key Takeaways)

  • Claude Code aik terminal agent hai; rozmarrah ki slash commands aur .claude/ folder iski jaan hain.
  • Tool aur Model ko alag alag chunein; provider key aapko saste ya free models par switch karne ki aazadi deti hai.
  • Sessions, checkpoints aur Git woh safety net hain jo YOLO mode aur Ralph loops ko safe banatay hain.
  • MCP connect karta hai, skills teach karti hain, plugins bundle karte hain — sab tools ke concept par chalte hain.
  • Pehle sab se light solution chunein. Agla qadam: autonomous workflow aur master cheat-sheet!
