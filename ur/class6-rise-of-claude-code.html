Class 6 · 6.1

Claude Code ka urooj: Tareekh, setup aur installation

Late-2024 ke ek mamooli side project se lekar billion-dollar tool banne tak — Claude Code ki hairan-kun kahani, yeh kyun itna ahem hai, aur ise VS Code ke andar step-by-step kaise install karein.

🎯 Maqsad: Claude Code install karein aur iski kahani samjhein⏱ Parhai: 9 min🧭 Qisam: Setup aur amli rehnumayi

01Ek side project se billion-dollar tool tak

Claude Code ka shandar safar late 2024 mein shuru hua, jab Anthropic ke ek qabil engineer Boris Cherny ne Claude CLI ke naam se ek chhota sa side project banaya, taake Claude ke sath ek agent loop ke zariye coding karwai ja sake. Wahan se is ne aisi raftaar pakdi ke dunya dekhti reh gayi.

Pehla CLI coding tool jis ne dunya bhar mein dhoom machayi — aur iske baad aane wali agentic lehar.

Anthropic ne ise April 2025 mein aam public ke liye generally release kiya (taqriban February se zyadatar developers ke paas mojood tha). Yeh pehli martaba tha ke terminal-based CLI tools mein se kisi ne itni mazboot pakad banayi — aaj darjanon tools samnay aa chukay hain, lekin is inqilab ka aaghaz Claude Code se hua tha. Phir September 2025 mein, V2 ne ek mukammal aur robust ecosystem pesh kiya: checkpointing, sub-agents, hooks, custom skills aur background tasks. Pichhle mahinon mein bohot se features aahista aahista test ho rahe thay jo V2 aate aate mature ho gaye. Claude Code ecosystem ke andar code likhne ke liye ek Claude Code SDK bhi launch kiya gaya — OpenAI Agents SDK ki tarah aam agent framework nahi, balkay khas Claude Code ke upar apne custom tools build karne ka zariya.

Aham tareen morr (The inflection point)

November 2025 mein, Anthropic ne apna sab se taqatwar model Opus 4.5 release kiya — jise technology ke maahireen agentic coding ki tareekh ka sab se bara turning point maante hain. Iske baad, Google ka Gemini 3 Pro aur OpenAI ka Codex / GPT-5.2 isi category mein dakhil huay — lekin Opus 4.5 pehla model tha jis ne sab ko yeh kehne par majboor kar diya ke ab waqai cheezein badal chuki hain: itna ba-aitemad agent jis par aap har diff check kiye bina asal production code ke sath bharosa kar saktay hain.

Taqriban usi doran, Anthropic ne Claude Code ke zariye $1 billion annual run-rate revenue (ARR) cross kiya — ek zabardast kamyabi. Aur January 2026 tak, unhon ne Cowork muta-arif karwaya, jo isi agentic concept ko coding se aagay aam office aur productivity kamo tak le gaya. Hum is course mein Cowork cover nahi karenge — kyunki yeh course khas coding ke baray mein hai — lekin yeh dekhne layaq cheez hai. Sath sath MCP (Model Context Protocol) ka ahem kirdar bhi samnay aaya: yeh late 2024 mein shuru hua, har jagah phail gaya, aur ab iske monthly 100 million downloads hotay hain. MCP Claude Code ecosystem ki reedh ki haddi hai, aur hum ise aage chal kar tafseel se cover karenge.

Hype mein apna tawazun na khoyen

AI ki dunya mein taqriban har haftay koi na koi bara dhamaka hota hai, aur insaan ghabra jata hai ke kya kya seekhay. Haqeeqi aur qabil-e-aitemad tools wahi hotay hain jo mahinon tak apni upyogita sabit karein. Claude Code itne arsay se maidan mein datt kar khara hai ke hum yaqeen se keh saktay hain yeh mustaqil qayam rehne wala tool hai.

02Pricing: Asal zaroorat kya hai?

Zyadatar AI products ki tarah yahan bhi pricing ko do alag hisson mein samjha jata hai — do mukhtalif maqasid ke liye products hain: API un developers ke liye hai jo apne banaye huay apps ke andar bar bar AI ko call karna chahte hain (jaisa ke pichhle hafte hum ne OpenRouter ke sath kiya tha). Doosra hissa Consumer subscription hai jo ek aam user ke liye hoti hai — aur is course mein hamara taaluq isi subscription plan se hai.

PlanPriceAap ko kya milta hai
Free$0ChatGPT ki tarah aam Claude website par chat karna. Hum yeh use nahi kar rahe.
Pro~$20 / mahinaWeb aur aap ke computer terminal dono par Claude Code — is course mein hum yahi use karte hain.
Max$100 ya $200 / mahinaHeavy daily programming ke liye bohot bari usage limits. Optional hai — aam learners ko iski koi zaroorat nahi.
Yeh bilkul ikhtiyari (Optional) hai

Aap bina ek rupiya kharch kiye bhi is course ke sath chal saktay hain — aaj aage chal kar hum Claude Code ke andar muft aur nihayat saste models chalana bhi seekhenge. Lekin official paid model par experience be-panah behtar aur smooth hota hai. Agar is course ke liye aap kisi ek cheez par thora kharch karna chahein, to Anthropic Pro subscription behtareen sarmayakari hai — ek mehnge laptop ke muqablay mein nihayat sasti lekin salahiyaton ka samandar. Pehle muft tareeqon se aaghaz karein, baad mein agar munasib samjhein to paid plan par switch karein.

03VS Code ke andar Claude Code install karein

Apne computer par Claude Code lana nihayat aasan hai — bas ek single command jo website khud aapke operating system ke mutabiq tayyar karke deti hai.

Anthropic mein sign in karein

claude.ai par jayein, Try Claude dabayein, aur apna account banayein (Google ya email ke sath). Yeh wahi account hai jis se Claude Code baad mein login karega.

Install command haasil karein

code.claude.com par jayein — yeh aapko Claude Code ki official site par redirect karega, jahan aapka operating system (Windows, Mac ya Linux) khud ba khud detect ho kar sahi single-line command samnay aa jayegi.

VS Code terminal mein paste karein

VS Code kholein, uska integrated terminal open karein (Ctrl+`, ya Ctrl/Cmd+J), wahan yeh command paste karein aur Enter dabayein. Claude Code khud ba khud install ho jayega.

Windows permissions ka masla?

Agar Windows par PowerShell yeh error de ke scripts chalana mana hai, to bilkul ghabrayein mat — yeh Windows ki aam standard setting hoti hai. Assistant se madad lein ya script permission enable karein, aur command dobara chalayein.

VS Code · terminal
# code.claude.com se aane wali single command paste karein
# ...installation complete hogi, aur phir:
✓ Claude Code installed — version 2.1.29
# aap ke paas is se naya version ho sakta hai — yeh bilkul theek hai

04Extension banam Terminal: Asal farq kya hai?

Hum VS Code ke liye official Claude Code extension bhi install karenge. Extensions panel kholein (Ctrl/Cmd+Shift+X), Claude Code search karein — verified tick wala pehla official result milega — ise install kar lein. Ab VS Code ke andar Claude Code use karne ke do tareeqay hain:

Sidebar extension

Zyada built-in, lekin mehdood

Top bar mein Claude icon dabayein to yeh sidebar panel ki tarah khul jata hai — bilkul Codex sidebar ki tarah. Yeh editor ke sath tightly integrated hai aur files ko achhi tarah control karta hai, lekin yeh shuruaati beginners ke liye bana ek packaged version hai jismein tamam advance pro features nahi miltay.

Terminal CLI

Mukammal taqatwar pro product

VS Code terminal ke andar seedha claude likh kar run karein. Aapko file explorer aur editor ke tamam faiday bhi miltay hain, aur sath sath Claude Code ka unconstrained, full-featured CLI power bhi milta hai. Poore hafte hum isi tareeqay par kaam karenge.

Ab hum professional vibe engineers ban chukay hain

Pehla week sidebars, visual cards, aur aam chats ke liye tha. Ab hum sanjeeda vibe engineering ki taraf qadam barha rahe hain — is liye hum seedha terminal ke andar kaam karenge taake Claude Code ki poori taqat hamare ikhtiyar mein ho.

✓ Aham Nakaat (Key Takeaways)

  • Claude Code Boris Cherny ke late-2024 side project se shuru hua; general release April 2025 mein hui aur mukammal V2 ecosystem September 2025 mein samnay aaya.
  • Opus 4.5 (Nov 2025) agentic coding ka turning point tha — is ne agents ko itna qabil banaya ke bina har diff check kiye unpar bharosa kiya ja sakay; Anthropic ne iske sath $1B ARR cross kiya.
  • Course ke liye sirf Pro plan (~$20/mo) kaafi hai — muft aur saste models ke raaste bhi mojood hain, is liye payment bilkul ikhtiyari hai.
  • code.claude.com se sirf ek command copy karke VS Code terminal mein paste karne se installation ho jaati hai.
  • Sidebar extension ke bajaye terminal CLI ko tarjeeh dein — yehi asal full-featured aur taqatwar tareeqa hai.
