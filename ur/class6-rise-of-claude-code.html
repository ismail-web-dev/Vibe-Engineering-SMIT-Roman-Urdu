Class 6 · 6.1

Claude Code ka aaghaz: history, setup aur installation

Late-2024 ke ek side project se lekar billion-dollar tool tak — Claude Code ki kahani, yeh kyun ahem hai, aur ise VS Code ke andar kaise install karein.

🎯 Goal: Claude Code install karein aur iski kahani jaanein⏱ Read: 9 min🧭 Type: setup

01Ek side project se billion-dollar tool tak

Claude Code ka aaghaz late 2024 mein hua, jab Anthropic ke ek engineer Boris Cherny ne Claude CLI naam ka ek side project banaya, taake Claude ke sath ek agent loop mein coding ki ja sake. Wahan se yeh aage badhta gaya.

Pehla CLI coding tool jo waqai mashhoor hua — aur is ke baad aane wali lehar.

Anthropic ne ise April 2025 mein generally release kiya (taqriban February se zyadatar logon ke liye available tha). Yeh pehli baar tha ke in CLI tools mein se koi ek samne aaya aur waqai jagah bana li — ab to tens of tools hain, lekin Claude Code se aaghaz hua tha. Phir September 2025 mein, V2 ne ek poora robust ecosystem pesh kiya: checkpointing, sub-agents, hooks, skills aur background tasks. Pichhle mahinon mein bohot se features roll out hue the lekin V2 mein mature hue. Claude Code ecosystem ke andar kaam karne wala code likhne ke liye ek Claude Code SDK bhi hai — OpenAI Agents SDK ki tarah general agent framework nahi, balki khud Claude Code ke upar build karne ka tarika.

Inflection point

November 2025 mein, Anthropic ne Opus 4.5 release kiya — unka sab se strong model, aur jise bohot se log agentic coding ka inflection point samajhte hain. Iske baad, Google ka Gemini 3 Pro aur OpenAI ka Codex / GPT-5.2 same tier mein aaye — lekin Opus 4.5 pehla tha jise dekh kar logon ne kaha ki kuch badal gaya hai: itne reliable agents jin par har diff check kiye bina real code ke sath bharosa kiya ja sake.

Taqriban usi waqt, Anthropic ne Claude Code ke sath $1 billion run-rate revenue (ARR) cross kiya — ek bari kamyabi. Aur January 2026 tak, unhon ne Cowork release kiya, jo is same idea ko coding se aage le jata hai. Hum yahan Cowork cover nahi karein ge — yeh course mukammal taur par coding ke baare mein hai — lekin yeh dekhne ke kabil hai. Is sab ke sath MCP (Model Context Protocol) ki kahani bhi chal rahi hai: yeh late 2024 mein samne aaya, jagah banayi, aur ab monthly 100 million downloads dekhta hai. MCP Claude Code ecosystem ka ek bara hissa hai, aur hum ise baad mein cover karein ge.

Hype mein na kho jayein

Aksar har week baray events hote hain, aur yeh overwhelming lag sakta hai. Powerful aur compelling tools woh hote hain jo kuch mahine tikte hain. Claude Code itne time se mojood hai ke hum jaante hain ke yeh hamesha rahega.

02Pricing: aap ko waqai kis cheez ki zaroorat hai

Aksar AIs ki tarah, pricing ko samajhne ke do tarike hain — do alag products. API aap ke apne products build karne ke liye repeated calls karne ke liye hai (jo hum ne pichhle hafte OpenRouter ke sath use kiya تھا). Consumer subscription ek user ke taur par aap ke liye hai — aur yahi woh plan hai jis ki humein yahan parwah hai.

PlanPriceAap ko kya milta hai
Free$0ChatGPT ki tarah sirf Claude se chat karna. Yeh woh nahi hai jo hum use kar rahe hain.
Pro~$20 / moWeb aur aap ke terminal mein Claude Code — course mein yahi use hota hai.
Max$100 or $200 / moHeavy daily use ke liye kafi ziada limits. Optional — zyadatar learners ko is ki zaroorat nahi.
Yeh optional hai

Aap kuch bhi pay kiye bina follow kar sakte hain — aaj baad mein hum Claude Code ke zariye free aur bohot cheap models set up karein ge. Lekin paid model par experience behtar hota hai. Agar is course ke liye kisi ek cheez mein invest karna banta hai, to Anthropic subscription ho sakti hai — ek enormous capability ke liye laptop se bhi sasta. Free se start karein, aur baad mein decide karein ke paid model add karna hai ya nahi.

03VS Code mein Claude Code install karein

Apne computer par Claude Code lana bilkul aasan hai — code ki ek line jo website aap ke operating system ke liye generate karti hai.

Anthropic mein sign in karein

claude.ai par jayein, Try Claude press karein, aur sign up karein (Google ya email). Yeh woh account hai jis se Claude Code log in karega.

Install command lein

code.claude.com par jayein — yeh Claude Code site par redirect karta hai, jo aap ka OS detect karke sahi one-line command dikhati hai. Agar aap mukammal docs chahte hain to click karein.

Ise VS Code terminal mein paste karein

VS Code mein, terminal kholein (Ctrl+`, ya Ctrl/Cmd+J), command paste karein, aur Enter press karein. Yeh Claude Code install kar deta hai.

PC permissions?

Agar Windows complain karta hai ki aap scripts chalane ke liye authorised nahi hain, to search karein ya assistant se poochein — yeh scripts ki ijazat dene ke liye ek standard aur harmless step hai. Ek baar ho jaye to command dobara run karein.

VS Code · terminal
# code.claude.com se one-line command paste karein
# ...installs, phir:
✓ Claude Code installed — version 2.1.29
# aap ka version newer ho sakta hai — koi baat nahi

04Extension vs. Terminal

Hum VS Code ke liye Claude Code extension bhi install karein ge. Extensions panel kholein (Ctrl/Cmd+Shift+X), Claude Code search karein — yeh top result hai, Anthropic ki taraf se, verified tick aur millions of downloads ke sath — aur ise install karein. Ab VS Code ke andar Claude Code use karne ke do tarike hain:

Sidebar extension

Zyada built-in, zyada constrained

Ise sidebar ke taur par kholne ke liye top bar mein Claude button press karein — Codex sidebar ki tarah. Yeh VS Code mein ziada baked-in hai aur editor ko thoda behtar control karta hai, lekin yeh bina tamam pro features ke ek ziada packaged, novice-friendly version hai.

Terminal CLI

Full-featured product

VS Code terminal mein claude run karein. Aap apne irid-gird file explorer aur VS Code tooling rakhte hain, yeh ab bhi aware hai ke VS Code ke andar hai — aur aap ko full-featured Claude Code milta hai. Tamam week hum yahi use karte hain.

Hum ab pros hain

Pehla week sidebars aur agent chats ke liye tha. Is week hum vibe engineers ban rahe hain — is liye hum complete, unconstrained Claude Code experience hasil karne ke liye terminal mein direct kaam karte hain.

✓ Aham baatein

  • Claude Code ka aaghaz Boris Cherny ke late-2024 side project se hua; general release April 2025, V2 ecosystem September 2025 mein aaya.
  • Opus 4.5 (Nov 2025) inflection point tha — real code ke sath agents par bharosa karne ke liye kafi reliable; Anthropic ne Claude Code par $1B ARR cross kiya.
  • Course ke liye aap ko sirf Pro plan (~$20/mo) ki zaroorat hai — aur free/cheap model routes baad mein aatein hain, is liye pay karna optional hai.
  • code.claude.com se VS Code terminal mein paste ki gayi single command ke sath install karein.
  • Sidebar extension ke bajaye terminal CLI ko prefer karein — yeh full-featured product hai.
