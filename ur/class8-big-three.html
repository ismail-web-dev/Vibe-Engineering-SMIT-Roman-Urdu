Class 8 · 8.1

MCP, Skills aur Plugins: Teen Baray Components

Course ka ek ahem turning point (inflection point). Teen aise bunyadi building blocks jo aap ke Claude Code ki taqat ko double kar dete hain — aur yeh sab ek hi bunyadi idea par khare hain: "tools". Yahan poora roadmap, is ke peeche ka asal technical breakthrough, aur un teeno mein se pehle component yani MCP ki tafseel samjhein ge.

🎯 Maqsad: Poora roadmap aur architecture samajhna⏱ Waqt: 12 min🧭 Type: Concepts

Kuch asbaaq aap ke learning curve ko bilkul nayi unchai par le jatay hain. Yeh sabaq unhi mein se ek hai. Week 2, Day 3 mein khushamdeed — aaj ka din aap ki expertise ko professional level tak le jaye ga. Hum un teen baray building blocks ko cover kar rahe hain jin ka AI agentic engineering mein har taraf charcha hai. Is sabaq ke aakhir tak aap ko mukammal samajh aa chuki hogi ke konsa tool kab aur kyun istemal karna hai.

Agar shuru mein bohot ziada lage to ghabrane ki zaroorat nahi

Aaj ka sabaq concepts ke aitbar se kafi wasee hai, aur pehli baar mein yeh thora heavy lag sakta hai. Yeh bilkul normal hai — hum is poore hafte aur agle hafte bhi inhi concepts par baar baar wapas aayen ge aur practical labs karein ge. Pehle round mein bas big picture samajhne par focus karein; aahista aahista har cheez clear hoti jaye gi.

01Teen baray components (The Big Three) ek nazar mein

Yeh baat seedhi Andrej Karpathy ke usi mashhoor tweet par wapas aati hai jis se hum ne course shuru kiya tha — jahan coding agents se behtareen output lene ke be-shumar aur uljhan paida karne wale tarike bayan kiye gaye thay. Yeh teen bunyadi pillars hain, aur in ke aapas ke talluq ko samajhna hi asal kamyabi hai:

Late 2024 se

🔌 MCP (Model Context Protocol)

Claude Code ko kisi doosray developer ke banaye hue tools se connect karne ka standard tarika — aasan lafzon mein "AI ke liye USB-C port".

Naya Concept

📄 Skills

Asan Markdown files (aur zaroorat parne par chotay scripts) ke zariye model ko domain expertise sikhana. Banane mein aasan, share karna nihayat aasan, aur context window par bilkul light.

Oct 2025

📦 Plugins

MCP servers, skills aur custom commands ka mukammal bundle, jise marketplaces ke zariye ba-aasani dhoonda aur install kiya ja sakta hai.

In teeno components ko aap alag alag install, uninstall aur apni marzi se activate kar sakte hain — aur yahi cheez shuru mein beginners ko confuse karti hai. Is liye hum inhein ek tarteeb se samjhein ge aur aakhir mein ek bilkul wazeh decision rule banayein ge ke konsa option kab choose karna hai.

02Har cheez ke peeche ek hi bunyadi idea: Tools

Is se pehle ke hum in teeno mein se kisi ko samjhein, aap ko us bunyadi technical breakthrough ko samajhna hoga jis ke ird-gird yeh saara nizam ghoomta hai. Yaad karein un chaar techniques ko jo ek aam LLM (jo bunyadi taur par predictive text on steroids hai) ko ek ba-ikhtiyar autonomous agent banati hain. Un chaar mein se sab se taqatwar aur numayan cheez hai: tools.

Jab model text generate karta hai, to woh aam alfaz ke bajaye aise specific tokens bhi produce kar sakta hai jo kisi action (amal) ko describe karte hain. Hamara software un tokens ko samajh leta hai ke "achha, model falana tool run karna chahta hai", hum system par woh tool execute karte hain, aur uska output model ko wapas bhej dete hain. Yahi poora magic hai! Yahi wajah hai ke aap Claude Code ko apni aankhon se terminal par files edit karte, tests chalate aur to-do items check karte dekhte hain. Anthropic ne Claude Code ke andar built-in tools ka ek zabardast set shamil kiya, aur yahi asal game-changer sabit hua.

Is bunyadi nukte ko zehen nasheen kar lein

Asal inqilab tools hain — yani model ke paas real world mein action lene ki taqat hona. MCP, Skills aur Plugins dar-asal model ko mazeed tools (ya tools jaise kaam karne ki salahiyat) provide karne ke mukhtalif tarike hain. Agar aap is ek baat ko zehen mein rakhein ge to aage ka saara architecture khud ba khud wazeh hota chala jaye ga.

03MCP — AI applications ke liye USB-C port

Late 2024 mein Anthropic ko yeh ehsaas hua ke agar hum koi aisa aam aur universal tarika nikal lein jis se kisi bhi teesray developer ke banaye hue tools ko Claude Code ke sath attach kiya ja sake, to AI ki salahiyat be-panah barh jaye gi. LangChain jaise frameworks ke paas pehle se tools ki libraries theen, magar har framework ka apna alag tarika tha — koi universal standard nahi tha. Is kami ko door karne ke liye Anthropic ne MCP (Model Context Protocol) muta-arif karwaya aur ise "AI applications ke liye USB-C port" qarar diya: yani AI apps ko external systems aur services se jorne ka ek open, universal standard.

MCP ke aaghaz mein teen cheezein theen: tools, prompt templates aur "resources" (data ya documents ke sets). In mein se jo cheez sab se ziada mashhoor hui aur jis ne dhoom machai woh tools ka feature tha. Lekin yahan ek barik nukta samajhna bohot zaroori hai: MCP khud koi tool nahi hai, aur na hi yeh koi specific code library hai. Yeh sirf ek protocol hai — yani ek aapas mein tay shuda zabita ya standard jis ke mutabiq tools banaye jate hain taake koi bhi MCP-compatible AI app unhein foran istemal kar sake.

MCP waqai itna bara inqilab kyun hai?

Is liye nahi ke is ke peeche koi bohot pecheeda science hai — aakhir LangChain wagaira pehle se aisi cheezein kar rahe thay. Asal taqat is baat mein hai ke ise poori industry ne bohot taizi se apna liya (wide adoption). Hazaron open-source servers, ready-made integrations, aur marketplaces ka ek wasee ecosystem wujood mein aa chuka hai — jis ki wajah se sirf ek line ki command likh kar aap Claude Code ko ghanton ke bajaye minute mein naye tools se lais kar sakte hain.

…aur is ki boundaries kya hain? (Over-hype se bachein)

Do haqeeqat-pasandana baatein zehen mein rakhein. Pehli yeh ke MCP sirf ek interface ya rasta hai, koi jadoo nahi — asal qeemat behtareen tools aur logic ki hai, na ke unhein jorne wale wire ki. Doosri aur sab se ahem baat: yeh context window bohot ziada khata hai (context-heavy hai). Agar aap shauq mein 10-15 baray MCP servers connect kar lein ge, to har tool ki definitions aap ke context window ko foran bhar dein gi. 2026 ke naye updates ne is mein behtari zaroor laayi hai (ab Claude Code har tool ko shuru mein load karne ke bajaye demand par lata hai), lekin had se ziada tools ab bhi performance ko girate hain aur compaction ko trigger karte hain. Yahi woh limitation hai jis ko hal karne ke liye Skills ka concept samnay aaya — jo hum agle sabaq mein seekhein ge!

✓ Aham Nakaat (Key Takeaways)

  • The Big Three: MCP, Skills aur Plugins — teeno model ko nayi tools aur salahiyatein dete hain; har ek ko azadana tor par install aur activate kiya ja sakta hai.
  • Core Breakthrough: Asal inqilab Tools hain — tokens jo action ko describe karte hain aur model ko sirf baatein karne ke bajaye amli tor par kaam karne ke qabil banate hain.
  • MCP (Model Context Protocol): AI ke liye "USB-C port" ki tarah ek open protocol hai, jo doosron ke banaye hue tools ko aap ki AI app se ba-aasani jod deta hai.
  • Asal Taqat: MCP ki asali taqat is ki universal adoption mein hai — hazaron tayyar servers aur tools ek single command se dastiyab ho jate hain.
  • Miyanah-ravi: MCP context window ziada leta hai aur bananey mein thora complex hai. Is ka halka-phulka aur asan mutabadil "Skills" hai jo hum aage parhein ge.
