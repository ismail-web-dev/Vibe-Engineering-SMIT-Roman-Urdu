Class 14 · 14.3

Agent SDK se Claude Code ko chalana

Ab mazedaar hissa — related tools ka chhota sa tour jinhein rathnay ya yaad karne ki zaroorat nahi. Pehla tool hai Claude Agent SDK. Naam ke bawajood yeh koi alag agent framework nahi hai. Yeh apne code ke zariye Claude Code ko chalane ka tareeqa hai — yani agent ki poori power, aap ke program ke control mein!

🎯 Goal: Python se Claude Code ko control karna⏱ Parhein: 13 min🌶 Type: Spicy demo

Is par lambay notes banane ki zaroorat nahi — yeh sirf ek overview hai taake aap ko pata ho ke yeh cheez exist karti hai. Lekin chukay yeh ek aam galat fehmi door karta hai, is liye ise samajhna kaafi mufeed hai.

01Agent SDK asal mein kya hai

Framework nahi — ek remote control hai

“Claude Agent SDK” naam sun kar lagta hai ke shayad yeh LangChain ya CrewAI jaisa koi framework hai. Aisa bilkul nahi hai! Yeh Claude Code ko programmatically chalane ka tareeqa hai — aap Python ya JS mein code likhte hain jo Claude ko ek prompt aur tools ki list deta hai, aur Claude khud sara agentic kaam anjam deta hai. (Pehle is ka naam Claude Code SDK tha; ghaur karein yahan naam mein agent singular hai.)

Wohi CLI wala engine — lekin ab aap ise apne code ke andar se call karte hain aur bilkul specify karte hain ke yeh kaun se tools use kar sakta hai.

02Chhota uv project set up karein

Hum uv (nihayat tez tareen Python tooling) use karenge. Ek khaali folder se shuru karein:

terminal
uv init --bare              # aik saaf suthra, khaali project
uv python pin 3.13
uv add python-dotenv requests claude-agent-sdk   # pip install ki tarah packages add karein
# apne ANTHROPIC_API_KEY ke sath .env aur aik .gitignore shamil karein

03Poora program

Bas itna sa poora code hai! Upar se neeche parhein — aap ki tawaqqo se kahin zyada seedha aur mukhtasar hai:

main.py
import asyncio
from dotenv import load_dotenv
from claude_agent_sdk import query, ClaudeAgentOptions

load_dotenv(override=True)   # system environment variables ke muqablay mein .env ko priority milegi

prompt = "Make a vanilla HTML + JS + CSS game of Space Invaders. " \
         "Write the code to files in the current directory, including index.html."

tools = ["Read", "Write", "Edit", "Bash"]   # woh tools jo hum Claude ko use karne ki ijazat de rahe hain

async def main():
    options = ClaudeAgentOptions(
        allowed_tools=tools,
        model="claude-opus-4-6",   # demo ke liye show-off kiya hai — warning zaroor parhein!
    )
    async for message in query(prompt=prompt, options=options):
        print(message)

asyncio.run(main())
Tight loop mein Opus use na karein

Is demo mein claude-opus-4-6 sirf visual maza dikhane ke liye lagaya gaya hai. Asal programmatic projects ke liye — khaas taur par kisi loop ke andar — hamesha sasta aur tez model (jaise Haiku ya Sonnet) chunein. Sab se mehnga model loop mein chalana aap ke wallet par bhari par sakta hai!

04Chalayein: game saamne aa jati hai

terminal
uv run main.py
# messages stream hokar wapas aate hain — file banti hai — kaam zabardast jari hai...
# done. index.html mukammal ho gaya.

index.html kholein aur dekhein: mukammal chalne wali Space Invaders game tayyar hai — start screen, arrow-key controls (jo hum ne prompt mein maangay bhi nahi the), sounds, score counter, aur upar march karte hue aliens. Vanilla HTML/JS/CSS mein Claude Code ka banaya hua complete game — aur yeh sab kuch us 20 lines ki choti si script ne drive kiya!

Haan, yeh thora fun / timepass project hai

Pehle hafte mein hum ne wada kiya tha ke hum sirf kaam ki cheezein banayenge aur koi faaltu timepass build nahi hoga. Isay woh exception samjhein jo rule ko sabit karti hai: Agent SDK aap ke prompt ke mutabiq kuch bhi bana sakta hai — chahe commercial tool ho ya game — kyunke background mein asal Claude Code engine hi chal raha hota hai.

05Isay kab use karein

Aap SDK ko rozmarra ke aam kamo mein use nahi karenge. Lekin agar aap poore Claude Code ecosystem ke upar apni koi nayi application banana chahein — apne program ke andar se is ki skills, plugins aur tools ko call karna ho — to Agent SDK hi rasta hai. Ise “terminal mein chat karne” se nikal kar “apne software ke andar agent ko embed karne” ka darwaza samjhein.

✓ Aham Nakaat (Key Takeaways)

  • Claude Agent SDK code ke zariye Claude Code ko drive karta hai — yeh koi naya agent framework nahi hai.
  • Aap isay ek prompt aur allowed tools ki list dete hain; query() messages ko stream karta hai.
  • Taqreeban 20 lines ki script ne pehli baar mein hi zero-shot mukammal playable Space Invaders game tayyar kar di.
  • Asal production aur loops wale kaam ke liye hamesha sasta aur tez model use karein — loop mein Opus chalana bohot mehnga parta hai.
  • Ise tab istemal karein jab aap ko Claude Code ke poore ecosystem ko apni banayi hui application ke andar embed karna ho.
