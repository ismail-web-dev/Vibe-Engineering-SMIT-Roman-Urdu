Class 6 · 6.3

OpenCode: GLM 4.7 jaise muft models chalayein

Claude Code ka ek azeem open-source mutabadil (alternative) — bilkul muft, frontier-level ke qareeb tareen models aazmane aur kisi bhi pasandeeda provider ko jodne ka sab se aasan tareeqa.

🎯 Maqsad: Muft model ke zariye code review karwana⏱ Parhai: 8 min🧭 Qisam: Tools aur practical setup

01OpenCode kya hai — aur ise install kaise karein

Aur ab ek bilkul mukhtalif aur rooh-parwar cheez: OpenCode (opencode.ai). Yeh Claude Code ka ek intehayi maqbool open-source mad-e-muqabil (competitor) hai, aur sach-much muft models use karne ka sab se seedha rasta hai — iske andar box se hi behtareen free models shamil miltay hain, aur sath hi dunya ke kisi bhi provider (Claude, GPT, Gemini waghera) ke kisi bhi model ko connect karne ki mukammal sahoolat mojood hai.

Installation ka tareeqa bilkul aasan aur aashna hai. Aap chahein to unki website se apne OS ke liye one-line installer use karein, ya — kyunki hamare paas pehle se Node.js install hai — seedha npm ke zariye install kar lein. Windows par choco bhi ek aasan rasta hai; warna npm har platform par bila-rok-tok kaam karta hai:

VS Code · terminal
# npm ke zariye global install karein:
npm install -g opencode-ai
# phir apne project folder ke andar jayein:
cd your-project
opencode

Apne purane PM project ko khol kar ek naya fresh terminal open karein taake naya system PATH update ho sake, aur phir opencode likh kar launch kar dein.

02Models aur unke kaam karne ke modes

Pehli hairan-kun cheez jo aap dekhenge: OpenCode khud ba khud un environments ko pehchan leta hai jahan aap pehle se login hain. Maslan isne foran mojooda OpenAI subscription ko detect kar liya aur seedha GPT-5.2 select karke start hua. Yahan teen ahem shortcuts zehan mein rakhein:

Tab

Plan ↔ Build

Agent ke do modes ke darmiyan switch karein — pehle ghaur-o-fikr karein (Plan), ya seedha amli kaam karein (Build).

Ctrl + T

Reasoning level

low → medium → high → extra-high. GPT-5.2 aam limits se kahin ziada gehra soch sakta hai.

/models

Model tabdeel karein

Claude Code ki tarah slash se commands aati hain. /models likh kar naya model chun lein.

Model list scroll karenge to aapko dunya ke mashhoor tareen muft open-source sitare nazar aayenge:

ModelCompany / MulkShuhrat aur Salahiyat
GLM 4.7Z.ai (Zhipu, China)Ghair-mamooli had tak taqatwar; developer community mein dhoom machi hui hai.
Kimi K2 / K2.5Moonshot AIShayad is waqt ka dunya ka sab se behtareen open-source coding model.
MiniMaxMiniMaxEk aur intehayi sanjeeda aur qabil open-source option.

03GLM 4.7 ke sath muft code review

Aayein GLM 4.7 chunte hain aur free model ka maza chakhte hain. Ise plan mode (Tab) mein dalein, pehle se bani hui purani review file delete kar dein taake model ko koi naqal ya hint na milay, phir yeh prompt dein:

Please review the entire project, carry out a code review, and write your feedback to code-review.md in the docs directory.

Model foran harkat mein aata hai — iska visual layout Claude Code se thora mukhtalif hai lekin rooh wahi hai: thinking indicator ghoomta hai, files scan hoti hain, aur yeh sab kuch bilkul muft chal raha hai. Chunke yeh plan mode mein hai is liye baghair ijazat ke file nahi likhega; ab Tab daba kar build mode par switch karein aur file likhne ka kahein:

Please go ahead and write the code review to docs/code-review.md, but don't start any further work yet.

Context ~34% se barh kar ~37% par jata hai, aur mukammal review tayyar ho kar samnay aa jata hai: executive summary ("overall assessment: good"), taqatwar pehlu (modular architecture), aur sab se barh kar asli khamiyan — hard-coded auth credentials, TypeScript strictness ke maslay, code duplication, aur error handling ki kamiyan. Ek nihayat lamba aur shandar professional document!

Shandar hai — lekin abhi frontier-level nahi

GLM 4.7 jaise behtareen model ke bawajood yeh Claude Opus 4.5 jaisi aala satah se thora peechay hai. Iska review parhne mein la-jawab hai, lekin is se waisi azaadana aur be-khata karkardagi ki tawaqqo na rakhein — mushkil tha ke yeh poori codebase ko bina tode itni safai se refactor kar pata jaisa Opus 4.5 ne kiya tha.

"Muft" cheezon ki koi pakki guarantee nahi hoti

OpenCode ne apni free limits ko bilkul wazeh nahi kiya — is waqt koi saaf quota nazar nahi aata. Agar aap intehayi ziada use karenge to speed aahista ho sakti hai, rate-limits aa saktay hain, ya error mil sakta hai. Ho sakta hai mustaqbil mein yeh policy tabdeel ho jaye, is liye isay zehan mein rakhein.

04Doosre providers connect karna

/models se mojooda models dikhte hain; /connect se naya provider shamil kiya jata hai. By default aap OpenCode Zen par hotay hain — unka muft models ka khusoosi package — plus jo kuch isne auto-detect kiya (maslan OpenAI).

OpenCode Zen (free)OpenAI Anthropic (Max ya API key)GitHub Copilot GoogleAzureBedrock LM StudioOpenRouterOllama (local)

Aap ise apni key ke sath OpenRouter par point kar saktay hain (muft aur saste models ka behtareen zariya), ya locally Ollama ke zariye apne computer par chalne wale models par — lekin local models ke liye bohot bhari computer chahiye: kam az kam 64 GB GPU RAM (ya Mac par 64 GB unified memory), kyunki gpt-oss-20B kafi nahi hota aur gpt-oss-120B chalane ke liye aam laptop dam tod dete hain.

Amli tajweez (Practical advice)

Muft models ke liye OpenCode Zen ke models use karein, ya apni key ke sath OpenRouter connect karein. Taqriban har kaam jo aap Claude Code mein karte hain, woh OpenCode mein bhi ba-aasani ho sakta hai — balkay yahan ek hi session mein mukhtalif models aapas mein tabdeel karne ki mazeed azaadi milti hai.

Bohot se developers OpenCode ke aashiq hain. Instructor ka zaati pasandeeda ab bhi Claude Code hai — kyunki poora platform khas Claude models ke mizaj aur taqat ke mutabiq tarasha gaya hai — lekin agar aap chahein to poora course OpenCode par bhi ba-khoobi mukammal kar saktay hain.

✓ Aham Nakaat (Key Takeaways)

  • OpenCode Claude Code ka ek taqatwar open-source mutabadil hai — muft models chalane aur kisi bhi provider ko jodne ka sab se aasan tareeqa.
  • npm ya OS installer se install karein, phir apne project folder mein opencode chalayein; Tab se Plan/Build mode aur Ctrl+T se reasoning level change hota hai.
  • Muft sitaray: GLM 4.7, Kimi K2.5, MiniMax — nihayat mutasir-kun, lekin frontier-level jitne be-khata nahi.
  • Plan mode amli tabdeeli se pehle sochta hai; files create aur modify karne ke liye Build mode mein switch karein.
  • Naye providers ke liye /connect use karein; muft tareeqon mein sab se behtareen OpenCode Zen aur OpenRouter hain — local Ollama ke liye nihayat bhari machine darkar hoti hai.
