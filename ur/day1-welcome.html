Class 2 · 2.1

Khushamdeed — aur aapka pehla build

Yeh AI coding course bilkul waise hi shuru ho raha hai jaise aage chalna hai: kisi boring syllabus ya lambi baaton se nahi, balki agle das minute ke andar aik real working app build karke. Chaliye shuru karte hain!

🎯 Maqsad: sirf aik sentence ke prompt se working app generate karna⏱ Parhne ka waqt: 7 min🧰 Tool: Cursor (free trial)

01Pehle hi din practical build — seedha result dekhein

Zyadatar courses lambi chori introductions, objectives aur formality se shuru hote hain. Lekin yeh course bilkul mukhtalif hai. Yahan aap ka pehla step hi seedha practical karna aur kuch real build karna hai. Theory samajhne ke liye aage bohot waqt milega — aur Class 3 poori isi par hai — lekin AI coding agents ki taqat dekhne ka sab se tez tareeqa yehi hai ke agent ko aik khali folder dein aur usay khud kaam karte dekhein.

Aaj ka aik rule

Is course ke har project ko is tarah design kiya gaya hai ke uski real commercial value ho. Sirf aaj ka din aik exception hai. Aaj hum sirf enjoy karenge aur maze se seekhenge — kyun ke in tools ki taqat mehsoos karne ka is se behtar koi tareeqa nahi ke bilkul zero se aik mukammal game tayyar kar di jaye.

02Cursor ka ta'aruf

Hum shuruat Cursor se kar rahe hain — yeh bohot zyada popular hai, chalana nihayat asaan hai, aur iska free trial bhi milta hai. Agar aap ka trial pehle hi use ho chuka hai, to aap screen par dekh kar follow kar sakte hain ya kisi bhi doosre agent tool ke sath chal sakte hain. Cursor asal mein VS Code ke oopar hi build hua hai, is liye agar aap ne pehle VS Code use kiya hai to iske menus aur shortcuts aapko bilkul familiar lagen ge.

3 min

Download aur install karein

Cursor.com par jayein aur apne operating system (Mac, Windows, ya Linux) ke liye installer download karein. Windows par install karte waqt terms accept karein aur default setting rakhein jo Cursor ko aapke PATH mein add karti hai. Mac par bas isay Applications folder mein drag kar lein.

Sign in ya sign up karein

Pehli baar launch karne par yeh sign in karne ka kahega. Apna free account bana lein — filhal ke liye trial bilkul kaafi hai. Agar window khali dikh rahi ho to File → New Window se fresh window khol lein.

Project folder open karein

Coding mein "project kholne" ka seedha matlab hota hai apna kaam karne wala folder select karna. Pehle apne computer par aik projects ka folder banayein, uske andar Instant naam ka naya folder create karein, aur usay Cursor mein open kar lein. Jab oopar left corner mein INSTANT likha nazar aa jaye, to samjhein aapka workspace ready hai.

Cursor ke teen panes: file tree, code editor, aur daayein taraf wo AI agent jisse aap baat karenge.

03Aik sentence ke prompt se game banayein

Daayein taraf ke panel mein aap LLM se direct guftagu karte hain — yeh aapka coding sidekick hai. Input box ke neeche model select karne ka option hota hai (paid plans par; warna auto par Cursor khud best model choose kar leta hai). Ab aap apna prompt type karein:

agent ko prompt
Please build a website for a 3D first-person shooter game
in an arena against one computer opponent, controlled by
arrow keys and space bar to shoot.

Prompt send karein. Agent foran harkat mein aa jata hai: pehle planning karega, files explore karega, aur phir code likhna shuru karega. Aap apni ankhon ke samne index.html bante dekhenge, sath CSS aur JavaScript ki files bhi. Kuch actions ke liye shayad yeh aapse permission mange — agar theek lage to allow kar dein — ya aapki settings ke mutabiq khud ba khud chalta rahega.

Double-click karein aur game khelein

Jab agent apna kaam mukammal kar le, to index.html ko apne browser mein double-click karke open karein. Arrow keys se move karein aur space bar se shoot karein. Aik mukammal playable 3D shooter game — sirf aik sentence ke prompt se tayyar, aur aap ne khud aik line code nahi likha!

Ab baat cheet ke zariye isay mazeed behtar banayein

Is exercise ka asal sabaq iteration hai. Chat jari rakhein aur agent wahi files modify karta jayega:

Prompt 1

"That's great. Please add some detail to the opponent so it looks more like an enemy."

Prompt 2

"Please add a heads-up display (HUD) and also make the difficulty harder."

Result

Aik challenging game jisme HUD aur behtar enemy model tayyar ho gaya — bina kisi manual coding ke, sirf natural English feedback se.

Aapka result mere result se thoda mukhtalif ho sakta hai

Agar aap yehi prompt das dafa chalayein ge to har dafa aik mukhtalif game banegi — kabhi aik file mein, kabhi teen alag files mein; kabhi shooting pehli baar mein perfect chalegi, kabhi koi chhota bug hoga. AI models ka yeh non-deterministic behavior bilkul normal baat hai, aur Class 3 mein hum isay tafseel se samjhein ge. Agar koi cheez sahi na chale, to bas agent ko batayein ke kya masla hai, ya Instant folder delete karke kisi doosre model ya behtar prompt ke sath dobara shuru karein.

04Pro level ka teaser: Ralph Loops

Yeh dikhane ke liye ke yeh technology aage kahan ja rahi hai, yehi same prompt humne Claude Code mein Ralph Loop technique ke zariye chalaya — yani zero-shot mode mein (sirf aik dafa instruction di aur beech mein koi manual guidance nahi di). Nateeja yeh nikla ke aik super polished shooter game ban kar aayi jisme health system, live mini-map, kill counter, aur shandar weapons shamil the. Kuch hi dino mein aap khud yeh sab build kar rahe honge. Ralph Loops ko hum Class 3 mein mukammal tafseel se samjhein ge.

✓ Aham Nakaat (Key Takeaways)

  • AI agents ko samajhne ka sab se tez tareeqa hai ke khud unhe use karein — pehle practical karein, theory baad mein aati rahegi.
  • Agent aam zubaan mein di gayi instruction leta hai aur aapke liye planning, code writing, aur iterative improvements khud karta hai.
  • Non-determinism normal baat hai: aik hi prompt se har dafa thoda mukhtalif nateeja aa sakta hai.
  • Aap poori development conversation ke zariye control karte hain — bas wazeh batayein ke aapko kya chahiye aur kahan behtari ki zaroorat hai.
