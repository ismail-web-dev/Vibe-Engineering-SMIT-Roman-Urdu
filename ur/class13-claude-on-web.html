Class 13 · 13.3

Web par Claude Code — remote chalane ke 5 tareeqe

Yeh woh feature hai jis ne sab ko hairan kar diya. Claude Code aap ke laptop par chalna band karke Anthropic ki machines par ready-made sandbox mein chalta hai. Aap ek waqt mein das tasks chala sakte hain, phone se control kar sakte hain, ya GitHub issue par @claude tag karke chale jayein.

🎯 Maqsad: managed cloud mein Claude chalana⏱ Parhein: 18 min🤖 Qisam: hands-on

Sandboxing (13.2) ne cheezen aap ki machine par rakhi theen. Ab connection kaat dete hain. Is tareeqe ke kai naam hain — remote execution, Claude Code on the Web — lekin khayal ek hi hai: kaam kahin aur hota hai, Anthropic ke infrastructure par pehle se sandboxed.

01Bara khayal: managed cloud sandbox

“Managed” ka matlab hai Anthropic machine chalata aur sambhalta hai; “cloud sandbox” ka matlab hai ke yeh remote aur isolated hai. Aap task bhejte hain; wahan naya Claude Code shuru hota, kaam karta aur jawab deta hai. Do cheezen isay waqai exciting banati hain:

parallelism

Ek waqt mein das tasks

“+” button daba kar kai Claudes chalane jaisa — farq sirf yeh ke yeh aap ke nahi Anthropic ke boxes par chalte hain. Aap ka laptop khaali rehta hai.

mobility

Chalte phirte kaam

Phone mein hidayat likhein, yeh cloud mein chalegi aur ghar pohanch kar laptop par jari rakhein. Pura conversation context task ke saath safar karta hai.

GitHub se mazbooti se juda hai

Cloud box ko aap ka code chahiye, is liye sab kuch GitHub ke zariye munazzam hota hai: aap ka kaam committed aur pushed hona chahiye. Cloud Claude repo clone karta, kaam karta aur branch wapas push karta hai taake aap Pull Request ki surat mein review karein.

02Ek martaba setup: GitHub connect karein

Pehli baar thori wiring karni hoti hai. Ek baar karein aur bhool jayein. (Anthropic is flow ko aksar badalta hai — current steps ke liye course resources zaroor dekhein.)

Claude ko GitHub se jorein

claude.ai/code par jayein → Connect to GitHub → authorise karein. Phir Connect repositories aur apne repo(s) mein Claude Code GitHub app install karein.

GitHub CLI install karein

Claude Code mein /install-github-app chalayein. Agar gh missing hua to Mac, Windows ya Linux ke liye exact command dega. Install karke gh auth login chalayein aur browser + one-time-code flow mukammal karein.

Apna code commit karein

git add . phir git commit karein taake git status clean ho. Cloud ko pushed kaam chahiye.

Workflows install karein

/install-github-app dobara chalayein, repo chunein aur prompt par dono GitHub workflows tick karein. Claude subscription ke saath aane wala long-lived token chunein, authorise karein aur GitHub khulne dein.

Setup PR merge karein

GitHub workflow files add karne wali Pull Request dikhayega. Create pull request → Merge → Confirm.

Abhi aap ne kya kiya

Aap ne repo mein do YAML files — .github/workflows/claude.yml aur claude-code-review.yml — add ki hain. Yeh bridge hai jo issue par Claude ko tag karke kaam dene deta hai. Setup mukammal.

03Remote chalane ke paanch tareeqe

Bridge tayyar hai, ab cloud mein dakhil hone ke paanch darwaze dekhein. Kuch der ke liye flaky ho sakte hain (yeh research preview hai) — har tareeqa aazmayein taake maloom ho ke maujood hai.

#TareeqaAap kya karein
1Ampersand prefixNormal Claude Code session mein hidayat se pehle & lagayein. Yeh local nahi chalta — poori conversation cloud ko bheji jati hai.
2Command lineTerminal se: claude --remote "…your task…". Yeh remote session mein chala jata hai.
3Browserclaude.ai/code par jayein, repo chunein aur task type karein. Chhota Claude Code cloud mein chalta aur PR push karta hai.
4Mobile appClaude app → Code tab → New session. Phone se bilkul browser jaisa tajurba. Dinner ke dauran features chala dein.
5GitHub issueIssue kholein, task bayan karein aur @claude tag karein. Anthropic cloud mein Claude chala kar kaam kar dega. ⭐ asal star.
terminal & claude
# way 1 — inside a Claude Code session:
> & redo my README and write a fresh architecture doc
# runs in the cloud; use  /tasks  to see everything running remotely

# way 2 — straight from PowerShell / bash:
claude --remote "read planning/*.md then design the market-data backend"
/tasks aap ka control tower hai

Kai remote jobs shuru karein, phir sab ko dekhne ke liye /tasks chalayein — cloud mein kai terminals kholne ke barabar. Yeh parallel chalte hain jab ke aap ki machine kuch nahi karti.

04Star: @claude tagged issue

Yeh woh workflow hai jo dil jeet leta hai. Aap aam ticket ki tarah GitHub issue likhein, @claude add karein, create dabayein — chand seconds baad Claude Bot to-do list post karke kaam shuru kar deta hai. Planning docs parhta, code likhta, tests chalata aur PR kholta hai. Aap ne sirf kaam bayan kiya.

Ab sochiye ek saath darjan issues raise hon — cloud Claudes ka fleet backlog par parallel kaam kare aur har ek reviewable PR wapas de.
Pichlay haftay ke saath milayein

Jira tickets ka setup yaad hai? Sochiye har ticket tagged GitHub issue ban jaye aur aap ke sote waqt Claude cloud mein sab clear kar de. Isi workflow ke liye poora setup worth it tha.

05Imandaar notes (yeh research preview hai)

  • Local se slow. Cloud mein document likhne mein taqreeban 10 minutes lag sakte hain. Sabr karein.
  • Thora flaky. Session jaldi ruk sakta hai — dobara kahen aur intezar karein. Research preview kehne ki wajah hai, dheere dheere stable hoga.
  • Poora context safar karta hai. Job cloud ko bhejte waqt ab tak ki poori conversation saath jati hai, is liye kaam be-rukawat jari rehta hai.
  • PR hamesha review karein. Cloud typing karta hai; merge kya hoga, faisla aap karte hain.

✓ Ahm baatein

  • Managed cloud = Anthropic aap ke liye remote sandbox mein Claude Code chalata hai; GitHub se juda hai.
  • Ek baar setup: GitHub connect, app + gh CLI install, dono workflows tick aur setup PR merge.
  • Dakhil hone ke paanch tareeqe: & prefix, claude --remote, browser, mobile aur issue par @claude.
  • @claude issue flow reviewable PR deta hai — parallel kaam ke liye kai issues raise karein.
  • Yeh preview hai: thora slow aur flaky, lekin poora conversation context har job ke saath safar karta hai.
